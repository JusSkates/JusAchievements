# JusAchievements

A modern, console-style [RetroAchievements](https://retroachievements.org) companion app for
Android. It's built for dual-screen handhelds like the **AYN Thor**, and works on any
single-screen phone, tablet or handheld.

> **Unofficial.** JusAchievements is a fan project. It is not affiliated with or endorsed by
> RetroAchievements. Game art, badges and data are loaded from RetroAchievements at runtime and
> belong to their respective owners.

## Download

Get the latest APK from the [Releases](../../releases) page and install it on your device
(you may need to allow installs from your browser or file manager).

To sign in you need your RetroAchievements **username** and **Web API key**
(retroachievements.org → Settings → Keys). The key is encrypted on your device with the Android
Keystore and is only ever sent to retroachievements.org.

## Features

- **Home:** your milestones (points, hardcore rank, games, unlocks, beaten, mastered, last
  activity) and your recently played games.
- **Recent / Library:** every game you have progress in. Filter by status and system; sort by
  recent, progress or A–Z.
- **For You:** on-device recommendations, each with a reason (nearly finished, stalled, on your
  Want to Play list, new on your favourite systems).
- **Top:** your 20 rarest unlocked achievements, rarest first.
- **Feed / Friends:** recent unlocks from the people you follow, and each friend's milestones.
- **Events:** Achievement of the Week and community event sets.
- **Game page:** box art, progress, and every achievement. Open one for its details and the
  community's comments and tips.
- **Glows:** gold for unlocked achievements, rainbow for ones under 3% of players have, blue for
  100%-complete games.
- **Make it yours:** colour themes, show or hide tabs, and loop your own music file (or the
  built-in ambient track, generated by the app).

## Screens

| Device | Layout |
|---|---|
| Dual screen (AYN Thor, or any second display) | One screen is the showcase (home or the selected game), the other has the tabs and lists. Swap them any time. |
| Wide single screen (landscape, tablet) | Lists on the left, showcase on the right |
| Narrow single screen (phone portrait) | Lists first; the showcase opens over them |

### Gamepad

| Button | Action |
|---|---|
| D-pad / left stick | Move the highlight |
| A | Open |
| B | Back (never quits the app) |
| L1 / R1 | Previous / next tab |
| L2 / R2 | Previous / next game in the current list |
| SELECT | Swap screens |
| Y | Refresh |

## Good to know

- RetroAchievements limits how often apps can ask for data. JusAchievements paces its requests
  and waits when asked, so a tab can occasionally take a moment to load.
- RetroAchievements only shares **hardcore** rank with apps; casual rank is on the website.
- Following and unfollowing people happens on the RetroAchievements website.

## Build from source

Requires JDK 17+ and the Android SDK (API 37). Open the folder in Android Studio, or:

```bash
./gradlew assembleDebug
```

`./gradlew assembleRelease` signs with your own key if `JA_KEYSTORE_PROPERTIES` points at a
properties file (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`); otherwise it uses the
debug key.

## Project layout

```
data/api      RetroAchievements Web API client (Retrofit + kotlinx.serialization), rate limiting
data          Credential store (Keystore AES-GCM), settings, repository, domain models
domain        Recommender
display       Second-display detection and launch
audio         Built-in synthesised music and custom-file playback
ui            Shared AppState, MainActivity (main display), CompanionActivity (second display)
ui/screens    Sign-in, navigator (tabs/lists), hero (home, game, achievement, friend)
ui/motion     Splash, screen-swap animation, glows
ui/theme      Colour themes
```
